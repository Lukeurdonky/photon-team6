======Instructions: ======
1. Install all dependencies by running the following commands in the terminal:
   chmod +x install.sh
   ./install.sh

2. Run Program by desktop shortcut or by refreshing terminal and running:
   python main.py
   

======Debian instructions: ======
1. Login to the Virtual Machine using the username and password: student

2. Download and extract the project zip file from GitHub

3. Install all dependencies using the commands in the terminal: chmod +x install.sh
                                                                ./install.sh

4. To open the program, use the desktop shortcut or close and reopen the directory terminal and type the following command: python main.py


======Database instructions: ======
1. To visualize Database through terminal:
   psql photon -c "SELECT * FROM players;"

2. Add players to the Database through player entry screen. Type in ID to try to query an existing player from the Database
