======Instructions: ======
1. Install dependencies with this in powershell terminal:
python -m pip install -r requirements.txt 

2. Run Program with:
python main.py

======Debian instructions: ======
1. Login to the Virtual Machine using the username and password: student

2. Download and extract the project zip file from GitHub

3. Install python using the command in the terminal: sudo apt install python3

4. Install the pip module using the command in the terminal: sudo apt install python3-pip

5. install the tkinter module using the command in the terminal: sudo apt-get install python3-tk

6. Open the terminal within the project file and type in the following command: python3 -m pip install -r requirements.txt

7. To open the program, type the command: python3 main.py
