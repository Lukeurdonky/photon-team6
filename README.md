======Instructions: ======
1. Install all dependencies by running the following commands in the terminal in the project directory:
   - chmod +x install.sh
   - ./install.sh

2. Run Program specifically through the desktop shortcut that is generated by the install script
   

======Debian instructions: ======
1. Login to the Virtual Machine using the username and password: student

2. Download and extract the project zip file from GitHub

3. Open the terminal and cd into the project folder

4. Install all dependencies using the commands in the terminal (In order):
   - chmod +x install.sh
   - ./install.sh

5. To open the program, double click on the desktop shortcut generated by the install script.

6. To test the traffic generator, make sure to run it any time before the 30 second gameplay time counts down to zero. (DEPRECATED for final project)
   - python3 python_trafficgenarator_v2.py


======Database instructions: ======
1. To visualize Database through terminal:
   psql photon -c "SELECT * FROM players;"

2. Add players to the Database through player entry screen. Type in ID to try to query an existing player from the Database
